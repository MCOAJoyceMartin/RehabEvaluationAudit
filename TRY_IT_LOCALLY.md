# Trying the v2 build locally

This zip is the full v2 source (engine + pipeline + UI), minus `node_modules`
and the build output — both are regenerated by the steps below.

## 1. Install & run

```
npm install
npm run dev
```

This starts a local dev server (Vite will print a URL, typically
`http://localhost:5173`). Open it in a browser.

## 2. Try it

Drag in `fixtures/james-askew-nethealth-batch.pdf` (bundled in this zip) —
it's a real 43-page PT + OT batch, so you'll see the discipline tabs, all 7
rubric sections, the episode timeline, goal lifecycle, treatment frequency
analysis, documentation similarity, and (since it's PT + OT) the
cross-discipline documentation-consistency panel. `fixtures/` has two other
sample PDFs you can try as well.

Nothing leaves your browser — PDF parsing and scoring both run client-side.

## 3. Verify the build (optional)

```
npm run build   # tsc -b + vite build — should complete with no errors
npm run lint    # oxlint
```

## 4. Deploying (when you're ready)

`vite.config.ts` is already set up for GitHub Pages at
`mcoajoycemartin.github.io/RehabEvaluationAudit/`, and
`.github/workflows/deploy.yml` auto-builds and publishes on every push to
`main` — same as before. Push this code to that repo's `main` branch and it
redeploys automatically; no manual build/upload step needed.
